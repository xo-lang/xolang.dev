> **Download Xo.** The [latest release](https://github.com/xo-lang/xo/releases/latest)
> on GitHub has archives for macOS and Linux (arm64 and x86-64) and
> Windows (x86-64). [Getting started](/docs/getting-started/#install)
> shows how to verify, unpack, and install one.

Xo is experimental and moves in 0.x minor versions. Each version is an
annotated git tag in the source repository; the
[tags](https://github.com/xo-lang/xo/tags) list them all. Binary
archives start with 0.25.2; every version also builds from source, as
[Getting started](/docs/getting-started/#build-from-source) shows.

Breaking changes can come with any 0.x version. 1.0 will be a
compatibility promise, code that builds keeps building, and the project
owner decides when Xo makes it. The [roadmap](/roadmap/) shows what is
left.
