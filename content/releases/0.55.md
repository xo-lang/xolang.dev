## 0.55.0 (2026-11-21)

Xo 0.55.0 is the first release in which every module of the standard library is Proven: all 96 modules meet the Proven bar on features, tests and performance (std/stdcov at 28bdba13c). It adds gRPC (clients, servers, interceptors, health, reflection, retries and balancing), std/ui for local-first web apps, a MySQL driver and much more of Postgres in std/sql, a TLS server with QUIC and Encrypted Client Hello, Brotli, schema migrations, the `sync` effect and `server` fields in the language, and faster code on arm64 and x86-64. It follows 0.51.1; 0.52, 0.53 and 0.54 were internal toolchain versions and were not published, so these notes cover everything since 0.51.1.

Some changes can stop a program that compiled with 0.51.1 from compiling, or change what it does. Each is listed under "Breaking changes" with what to do.

### Security

Upgrade every program built with 0.51.1 or earlier, and rebuild it, since std is compiled into the binary. Unless an item says otherwise, 0.51.1 and earlier are affected.

**TLS** (std/tls, std/http):
- A TLS 1.2 CBC record's MAC is computed and checked in constant time whatever its padding (Lucky13), and is checked with Arm's DIT bit set where the CPU has it (decision 0619).
- A server that requires a client certificate no longer resumes a session ticket sealed by a configuration without client authentication (GO-2026-4337).
- A TLS 1.3 server refuses a ClientHello record that carries another handshake message after the ClientHello (GO-2026-4340).
- A server's "unsupported application protocols" error quotes the client's ALPN names, so a client cannot write control bytes into a log (GO-2025-4008).

**Paths and names with a NUL byte**: an `Fs` path or symlink target holding a NUL byte is refused, so `..\0` can no longer escape a sub `Fs`; `dial`, `listen` and `lookup_host` refuse a host or port with a NUL byte, which the darwin and Windows resolvers cut short (GO-2026-4971 class).

**HTTP/2** (std/http, native backends): the client checks the server's SETTINGS values as Go 1.26.11 does (GO-2026-4918); a connection returns flow control window for bodies only as handlers read them, so a client cannot make a server buffer unbounded request bodies.

**Inputs that cost far more than their size** (denial of service):
- std/xml and std/protobuf: decoding stops at 10,000 nesting levels, as Go's encoding/xml and protowire, where a deep document overflowed the stack.
- std/norm: a long run of combining marks normalizes in linear time (about 22 s for 1 MB of marks before).
- std/jpeg, std/png: a small file whose header asks for a huge image no longer allocates it, and a header too large for an Int is refused.
- std/url: `url.Values` with many keys is linear; std/amqp refuses lists, maps and arrays that declare more elements than their bytes can hold.

**Faults on peer input**: std/csv fields are valid UTF-8 (a 7 byte file faulted `csv.format`), and `uuid.parse` of some multi-byte texts faulted while building its error.

**macOS trust settings** (std/x509): `system_roots` applies the user and admin trust settings, so a root marked Deny for SSL is left out (GO-2022-0171).

### Breaking changes

Language and tools:
- **The `sync` effect** (decision 0662): a closure that uses a captured `Chan`, `Mutex` or `Atomic` performs `sync`, which a pure function type refuses (XO0701). Add `uses sync` to the function type. std/sql's `each`, `copy_from`, `on_notice` and `on_trace` callbacks are `uses sync` types, so closures that capture an Atomic or a Mutex pass again.
- **`Clock` takes its effect as a parameter** (decision 0652): `os.clock` is a `Clock[clock]` and `time.virtual(start)` a `Clock[()]`. Std fields that keep the OS clock name `Clock[clock]`; write the parameter where you name the type.
- **`xo --phase-times`**: a phase line ends `heap_mb=N peak_mb=N` instead of `(heap N MB, peak N MB)`. Read the two `key=value` fields.

std/http and std/tls:
- `Router.handle`, `handle_stream` and `mount` fault on a route that conflicts with one registered before, as Go's ServeMux panics. Remove the duplicate or make one pattern more specific.
- A failed TLS handshake is `ClientErr.Tls(err: tls.TlsErr)`, where it was a protocol error. Match `ClientErr.Tls` and read `err.kind`.
- A client with `Verify.Full` and an empty host fails, as Go's "either ServerName or InsecureSkipVerify must be specified". Pass the server's name as `host`.
- TLS alerts and errors follow Go: a TLS 1.2 server requiring a client certificate that gets none sends handshake_failure; a client whose peer closes mid-handshake reports `EOF`; an IP address host is not sent as SNI; a TLS 1.3 client whose verification fails sends bad_certificate; a `tls.server` without certificates answers unrecognized_name. Code matching the old alert names updates them.

std/json, std/time, std/netip:
- A Map key in a `DecodeErr` path is written `["KEY"]`, quoted, not `.KEY` (decision 0725), so a peer's key cannot forge a log line. Match on the new form.
- `time.Date` encodes in JSON as its text, `"2024-02-29"`, not as an object, and decoding checks the date. Stored JSON in the old form needs a one-time rewrite.
- `netip.ParseErr` keeps Go's parts (`what`, `input`, `msg`, `at`) and builds its text in `display()`; `msg` is now the reason alone. Use `display()` for the full text.

std/sql (drivers written in Xo):
- `DriverConn` gains `copy_to(q, out)` (decision 0679), `pipeline`, `wait_notification` and `notices`, and `TraceOp` gains `CopyTo`. A driver adds the methods; the CHANGELOG gives a stub for each that returns an error.

std/crypto:
- `Hash` gains `Blake2b_256`, `Blake2b_384`, `Blake2b_512`, `Keccak256` and `Keccak512`, and `Aead` gains `XChaCha20Poly1305`, so an exhaustive `match` with no `_ =>` arm is XO0301. Add the variants or a `_ =>` arm.

std/ui:
- An `ui.App{...}` literal now needs `confirm` (confirmed Msgs, `.confirming(...)`). Build Apps with `ui.app(init, update, view)`.

std/migrate:
- `up`, `status` and `has_pending` given no migration fail with `MigrateErr.NoMigrations`, as goose's ErrNoMigrations. Code that ran them on an empty directory handles the error.
- `MigrateErr.Missing` is `Missing(versions, newest, to)` with goose's text. Update patterns and constructors.

std/protoparse and std/protodesc:
- A .proto file with no `syntax` statement is proto2, as protoc reads it. Add `syntax = "proto3";` to such a file; `parse` also rejects what protoc's grammar rejects.
- An option value and a field's `default_value` are `Bytes`, as protoc keeps them (`"\377"` is byte 0xFF). Read them as Bytes.

std/yaml:
- Decode errors spell the target type as Xo does (`into Int`, `into Str`, `into Duration`; were Go's `int`, `string`, `time.Duration`). Code that matches those messages matches the Xo names.

### Highlights

**The standard library is Proven.** Every one of the 96 std modules has Go's tests ported where they apply, race, stress, fuzz and review evidence, and a timing row against Go's package (decision 0726). The std coverage page on xolang.dev shows each module's evidence.

**gRPC** (std/grpc, std/grpchealth, std/grpcreflect; `xo proto gen` generates typed stubs from a `service` block): interceptors (decision 0703), service config and retries (decision 0705), keepalive, client balancing over several addresses, DNS and custom resolvers, Unix sockets, per-RPC credentials, compression, stats handlers, response metadata, health checking and server reflection, as grpc-go.

**std/ui, local-first web apps** (decision 0659): a server-rendered App with live updates over a socket, a browser client that predicts, sign-in and redaction (decision 0664), per-user state, rooms that step a shared state at a fixed rate (decision 0695), `server` fields that never reach a client (decision 0719), and stores in a directory, Postgres or an S3 style bucket, so many instances behind a load balancer act as one App (decision 0686).

**Databases** (std/sql): a MySQL driver written in Xo (decision 0648), prepared statements, several result sets, batches, pool stats, and cancellation on both servers; Postgres COPY in both directions, large objects, ranges, composites, arrays, numeric (`sql.Numeric`), named arguments and typed readers as pgx parses them (decision 0679); std/migrate runs goose's `.sql` migrations, layouts and dialects.

**TLS and crypto**: the TLS server side (Go's `tls.Server`), session tickets, QUIC's TLS, Encrypted Client Hello (RFC 9849), version, cipher and curve settings; Hybrid Public Key Encryption (std/hpke), SHAKE and cSHAKE, BLAKE2b, Keccak, XChaCha20-Poly1305, PBKDF2, Ed25519ph, RSA-PSS over a digest, and the crypto/subtle helpers; x509 certificate pools, revocation lists, OIDs and Go's key encodings.

**Compression and encodings**: Brotli encode and decode with streaming compressors (decision 0666), and Brotli response encoding in std/http; Protocol Buffers editions 2023 and 2024, prototext, protojson options, descriptors byte for byte with protoc, well known type helpers and `derive Asn1` (decision 0661); CBOR tags, big integers and times; OTLP over gRPC and JSON with logs; Prometheus OpenMetrics and protobuf exposition, histograms and summaries.

**Language and tools**: `pub open enum` (decision 0649); `derive Cbor` tags (decision 0665); `List.filled`, `Bytes.into_builder` (decision 0722), `Mutex.try_with`, the rest of Go's float math and many List, Str and Bytes methods; `xo test --since=REV`; `xo build --list-inputs`; WASI reactors with `xo build --lib=shared` (decision 0688); new `xo vet` notes for costly Go idioms; `xo fix --vet=CODES`; and a riscv64 assembler and ELF linker (decision 0645 stage 1, no command yet).

### Performance

- arm64 and x86-64: loop splitting (decision 0724) keeps a loop's hot path free of the spills a call on a rare path forced; values that would spill across calls may stay in caller-saved registers; Float constants are one load; byte loads joined into one word; constant table reads folded.
- std/crypto on x86-64: AES-GCM, AES-CBC decryption, ChaCha20, ChaCha20-Poly1305, Poly1305 and SHA-3 run Go's vector and carry-less paths.
- Every std module has a timing row against Go's package in std/evidence (decision 0726); std/brotli's rows are in std/evidence/brotli/perf.md.

### Fixes

227 fixes, among them wrong output from a generic function instantiated with two types of one runtime form (task #469), tasks waiting inside `task.with_timeout` that faulted as deadlocked, an HTTP server freeing a task scope that was still running, heap growth under the default `XO_THP=dense` on Linux (task #355), deferred code over 5 seconds now faulting on wasm too, and many values near Int's largest that faulted in std/http, std/cron, std/sql and std/backoff. CHANGELOG.md lists each one.

### Known issues

- **`--race` memory** grows per task spawned, as in Go's `-race`.
- **windows/arm64 has no `--race`** (ThreadSanitizer has no windows/aarch64 runtime).
