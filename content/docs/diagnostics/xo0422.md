A field's wire string may carry options after a comma, as in a Go struct tag: `name as "key,omitempty": T`, or `as ",omitempty"` to keep the default key. `omitempty` leaves the field out when its value is empty (None, false, 0, "", or no elements); `string` writes a scalar as a JSON string holding its literal (decision 0555). Each may appear once. Go's `omitzero` does not exist in Xo. Remove the option. See core 2.2 and decision 0309.

## Example

```xo
struct User {
  id as "id,omitzero": Int
} derive Json
```

## Fix

```xo
struct User {
  id as "id": Int
} derive Json
```
