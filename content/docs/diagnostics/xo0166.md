A `while` loop with a condition may end without producing a value, so it is a statement. Only the infinite loop `while { ... }` is an expression, whose value comes from `break`. Move the loop into its own statement and compute the value separately. See core 3.5.

## Example

```xo
fn f(a: Bool) {
  let x = while a { }
}
```

## Fix

```xo
fn f(a: Bool) {
  while a { }
}
```
