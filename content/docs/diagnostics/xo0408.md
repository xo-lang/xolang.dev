A `const` initializer may use only literals, other constants, struct and enum construction, and collection literals of those. Calls and runtime values such as parameters are not compile time values. Use a `let` binding, or compute the value with a function. See core 3.1.

## Example

```xo
fn g() -> Int { 1 }

const X = g()
```

## Fix

```xo
const X = 1
```
