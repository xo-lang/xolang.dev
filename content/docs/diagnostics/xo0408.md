A `const` declared inside a function body may use only literals, other constants, struct and enum construction, and collection literals of those. A top level `const` may also call effect free functions: it is computed once, on first use (decision 0332). Move the constant to the top level, or use a `let` binding. See core 3.1.

## Example

```xo
fn g() -> Int { 1 }

fn f() -> Int {
  const X = g()
  X
}
```

## Fix

```xo
fn g() -> Int { 1 }

const X = g()

fn f() -> Int {
  X
}
```
