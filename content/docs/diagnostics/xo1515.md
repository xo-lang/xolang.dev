A component runs with only the imports of its world: wasi:http/proxy for a program that calls http.serve_component, wasi:cli/command for any other. The message names the call and how the program reaches it. Only code the program can reach counts: a std function nothing calls is not in the build. (Decision 0447.)

## Example

```xo
os.fs.read(path)
```

## Fix

```xo
Remove the call from the handler's path, embed the data with `embed`, or build the program natively.
```
