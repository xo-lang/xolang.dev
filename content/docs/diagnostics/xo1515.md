A component runs with only the imports of the wasi:http/proxy world. The message names the call and how the program reaches it. Only code the program can reach counts: a std function nothing calls is not in the build. (Decision 0447.)

## Example

```xo
os.fs.read(path)
```

## Fix

```xo
Remove the call from the handler's path, embed the data with `embed`, or build the program natively.
```
