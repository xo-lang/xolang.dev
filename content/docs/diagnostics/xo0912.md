`xo vet` reported this warning in 0.33.0, when a `uuid.Uuid` was a newtype over its canonical text. Since 0.34.0 it is two Ints (its 128 bits): there is no `.0` and no construction from a text, so the checker rejects those uses and vet no longer reports the code. `u.display()` (or `"${u}"`) gives the text, `uuid.parse(s)` checks a text and makes a Uuid, `u < v` orders Uuids as their bytes.

## Example

```xo
let key = id.0
```

## Fix

```xo
let key = id.display()
```
