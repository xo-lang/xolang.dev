A string literal `"..."`, raw string `r"..."` or `r#"..."#`, bytes literal `b"..."`, or triple quoted string `"""..."""` reached the end of the line (or file, for triple quoted strings) without its closing delimiter. Plain strings cannot span lines; use a triple quoted string for multi line text. A raw string opened with `r#"` must close with `"#`. See core 1.6.

## Example

```xo
fn f() -> Str {
  let s = "abc
  s
}
```

## Fix

```xo
fn f() -> Str {
  let s = "abc"
  s
}
```
