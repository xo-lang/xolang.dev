The operation does not exist for this type: arithmetic between `Duration` and a plain integer literal, `Time + Time`, indexing a `Str` by position, slicing something other than `List`, `Bytes`, or `Str`, `for` over a value that is not a List, Set, Map, Chan, Bytes, or range, `??` on a non optional, or `expect(x)` without a comparison. Durations need units (`5s`), and a `Str` is read with `runes()` or by slicing. See core 2.1, 3.5, and 3.6. Coming from Go: knowledgebase/guides/option-result-for-go.md maps `if err != nil`, `v, ok := m[k]`, error wrapping, and errors.Is to Xo (https://github.com/xo-lang/xo/blob/main/knowledgebase/guides/option-result-for-go.md).

## Example

```xo
fn f(d: Duration) -> Duration { d + 5 }
```

## Fix

```xo
fn f(d: Duration) -> Duration { d + 5s }
```
