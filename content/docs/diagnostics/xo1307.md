When the main module has vendor/modules.txt, builds use vendor/ only: no module cache, no network. Every requirement of xo.mod must then be vendored at its version (or above, as minimal version selection chose), and vendor/ must be readable. xo.mod changed since the last `xo vendor`; run it again. A vendored tree that was edited is XO1304 instead. See core 4.2 and decision 0086.

## Example

```xo
// xo.mod now requires v1.5.0, vendor/modules.txt still lists
# github.com/acme/billing v1.4.0
```

## Fix

```xo
xo mod tidy
xo vendor
```
