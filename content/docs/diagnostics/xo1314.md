XO_PROXY is a list of proxy URLs (http or https), `direct` (git), and `off`, separated by commas (try the next source only after "not found") or pipes (after any error); the default is `direct`. XO_NOPROXY and XO_NOSUMDB are comma separated path patterns (`github.com/acme/*`, `*.corp.example.com`). XO_SUMDB is `off` (the default) or a log's verifier key and optional URL. This code is reported when one of them cannot be parsed, or when the checksum log could not be consulted for a first fetch (unreachable, no record of the version, malformed answers): the version is not cached rather than cached unverified. A log that answers but contradicts the fetched content is XO1313 instead. See decisions 0124 and 0126.

## Example

```xo
XO_PROXY=ftp://mirror.example.com xo build .
```

## Fix

```xo
XO_PROXY=https://mirror.example.com,direct xo build .
```
