xo built for wasip1/wasm runs under WASI preview1, which has no processes, sockets or threads. `check`, `fmt`, `vet`, `explain`, `asm`, the lookups (`def`, `refs`, `type`, `symbols`, `doc`, `query`, `edit`) and `build` for every native target (Xo's own backends, assemblers and linkers) work. `run`, `test`, `bench`, `serve`, `lsp`, `mcp`, `replay`, `dump`, `dev`, `bind`, the module commands (`get`, `mod`, `vendor`, `publish`, `audit`), and `build` with `--backend=llvm`, `--backend=go`, `--race`, `--watch` or `--ld=system` need one, and print `xo: COMMAND is not available in the WASI build` with exit status 2. Run them with the native xo.

## Example

```xo
xo run .
```

## Fix

```xo
xo build -o prog . && run prog with the native xo
```
