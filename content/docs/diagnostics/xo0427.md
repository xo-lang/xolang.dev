A call of `xml.encode_value` or `xml.decode` is compiled as a call of the function `derive Xml` generates for its struct, so the type must be known where it is called. Call it with the struct, or take the decoder as a function value. See core 2.9.

## Example

```xo
fn read[T: Xml](s: Str) -> T ! xml.XmlErr {
  xml.decode[T](s)
}
```

## Fix

```xo
fn read_item(s: Str) -> Item ! xml.XmlErr {
  xml.decode[Item](s)
}
```
