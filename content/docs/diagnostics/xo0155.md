A duration literal is a decimal integer followed by one of `ns`, `us`, `ms`, `s`, `m`, or `h`: `5s`, `250ms`. Any other suffix on a number (`5sec`, or `0xg`, where `g` is read as a suffix) is reported here, and so are fractional or non decimal durations such as `1.5s` or `0x10s`. Write a fractional duration in a smaller unit: `1500ms`. See core 1.6.

## Example

```xo
const TIMEOUT = 1.5s
```

## Fix

```xo
const TIMEOUT = 1500ms
```
