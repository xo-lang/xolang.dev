Effect labels are `net` (`net.dial`, `net.listen`), `fs` (`fs.read`, `fs.write`), `clock`, `rand`, `env`, `proc`, `stdio`, `ffi`, and `go` for calls into Go packages, plus effect variables declared as `fx: Effects`. Any other name in a `uses` clause or effect argument is an error, as is an effect argument that is not a label, variable, or parenthesized list of them. See core 6.1.

## Example

```xo
pub fn g() uses network {}
```

## Fix

```xo
pub fn g() uses net {}
```
