`opt?` returns `None` from a function that returns an optional. In a function that returns a `Result` there is no error value to return for `None`, so say which error a missing value is: `opt.or_err(E.Missing)?`. The diagnostic offers that fix. Directly in a test block (not in a helper function or a fn literal), `opt?` fails the test with `missing value: opt` instead (decision 0347). See core 2.5. Coming from Go: knowledgebase/guides/option-result-for-go.md maps `if err != nil`, `v, ok := m[k]`, error wrapping, and errors.Is to Xo (https://github.com/xo-lang/xo/blob/main/knowledgebase/guides/option-result-for-go.md).

## Example

```xo
enum E { Missing }

fn f(s: Str?) -> Str ! E { s? }
```

## Fix

```xo
enum E { Missing }

fn f(s: Str?) -> Str ! E { s.or_err(E.Missing)? }
```
