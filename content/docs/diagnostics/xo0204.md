`opt?` returns `None` from a function that returns an optional. In a function that returns a `Result` there is no error value to return for `None`, so say which error a missing value is: `opt.or_err(E.Missing)?`. The diagnostic offers that fix. See core 2.5.

## Example

```xo
enum E { Missing }

fn f(s: Str?) -> Str ! E { s? }
```

## Fix

```xo
enum E { Missing }

fn f(s: Str?) -> Str ! E { s.or_err(E.Missing)? }
```
