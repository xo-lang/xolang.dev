The arm body of `p1 | p2` runs for either alternative, so every alternative must bind the same names with the same types; otherwise a name would be unbound in one case. Bind the name in every alternative, or bind it in none and use separate arms. See core 3.5.

## Example

```xo
fn f(r: Result[Int, Int]) -> Int {
  match r {
    Ok(v) | Err(_) => v
  }
}
```

## Fix

```xo
fn f(r: Result[Int, Int]) -> Int {
  match r {
    Ok(v) | Err(v) => v
  }
}
```
