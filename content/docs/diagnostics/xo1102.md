The Go package exports this function, method, or type, but its signature uses something the binding cannot express in Xo (for example complex numbers, channels, or unsafe pointers), so the binding skipped it. Skipped names and their reasons are listed at the top of the generated binding. Use another function, or write a small Go wrapper with a mappable signature. A name that does not exist at all is XO0601 instead. See core 4.4.

## Example

```xo
use go "strconv"

fn f() {
  strconv.parse_complex("1", 128)
}
```

## Fix

```xo
use go "strconv"

fn f(s: Str) -> Float ! Error {
  strconv.parse_float(s, 64)?
}
```
