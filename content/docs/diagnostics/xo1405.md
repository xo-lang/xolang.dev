A real-time function (core 6.5) may not wait for other tasks or the operating system: channel operations, `for` over a channel, `Mutex.with` and `with_read`, `scope`, `select`, spawning and awaiting tasks, `dbg`, and capability calls are rejected. It may declare no effect besides `ffi`. Atomic operations do not block and are allowed: share state with the rest of the program through Atomic values, or pass the data in and out as arguments.

## Example

```xo
fn tick(c: Chan[Float], x: Float) uses realtime {
  c.send(x)
}
```

## Fix

```xo
fn tick(level: Atomic[Int], x: Float) uses realtime {
  level.set(Int(x * 1000.0))
}
```
