Numeric conversions such as `Int(x)` and `Float(x)` take a number. Text is not a number: parse it with `Int.parse(s)`, which returns `Int?`, and decide what a bad input means. See core 2.1.

## Example

```xo
fn f(s: Str) -> Int { Int(s) }
```

## Fix

```xo
fn f(s: Str) -> Int { Int.parse(s) ?? 0 }
```
