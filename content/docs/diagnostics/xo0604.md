Packages may not import each other in a cycle, in one module or across two, so every package can be checked and built after its dependencies. Move the shared declarations into a third package that both import, or merge the two packages. Requirement cycles between modules (xo.mod require lines) are allowed and resolved by minimal version selection (core 4.2). See core 4.1.

## Example

```xo
// a/a.xo
use example.com/app/b

pub fn fa() -> Int { b.fb() }

// b/b.xo
use example.com/app/a

pub fn fb() -> Int { 1 }
pub fn g() -> Int { a.fa() }
```

## Fix

```xo
// a/a.xo
use example.com/app/b

pub fn fa() -> Int { b.fb() }

// b/b.xo (no longer imports a)
pub fn fb() -> Int { 1 }
```
