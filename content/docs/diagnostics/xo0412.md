A field's wire name (`name as "key": T`) is its JSON key or SqlRow column and cannot be empty. Write the key, or leave out `as` to use the field's name. See core 2.2.

## Example

```xo
struct User {
  name as "": Str
} derive Json
```

## Fix

```xo
struct User {
  name: Str
} derive Json
```
