A wasi:http host calls a component's handle export and never starts a module, so a preview 1 build of this program could not serve. Name the component's target. (Decision 0447.)

## Example

```xo
http.serve_component(r)
```

## Fix

```xo
Build with `xo build --targets=wasip2/wasm`.
```
