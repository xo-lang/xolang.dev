`use` takes a slash separated module path (`use std/http`, `use github.com/acme/billing/invoice`) or, for Go packages, `use go "path"` with a non empty, relative, plain string. Empty segments (`std//http`), a missing path, an empty or absolute Go path, and interpolation in a Go path are rejected. See core 4.1 and 4.4.

## Example

```xo
use std//http

fn ok() -> http.Response { http.text(200, "ok") }
```

## Fix

```xo
use std/http

fn ok() -> http.Response { http.text(200, "ok") }
```
