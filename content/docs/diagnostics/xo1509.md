Files are embedded at build time, so `embed` is only a constant's whole initializer, the constant declares its type (`Str`, `Bytes`, or `embed.Dir`), and the path is one string literal without interpolation. A module that declares its own `embed` uses it instead.

## Example

```xo
const PAGE = embed("index.html")
```

## Fix

```xo
Declare the type: `const PAGE: Str = embed("index.html")`.
```
