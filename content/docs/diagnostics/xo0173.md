All `use` declarations of a file come first, before any `fn`, `struct`, or other declaration, so a file's imports are visible at the top. Move the `use` up. See core 4.1 and 15 (File).

## Example

```xo
fn f() -> Int { 1 }
use std/http

fn ok() -> http.Response { http.text(200, "ok") }
```

## Fix

```xo
use std/http

fn f() -> Int { 1 }

fn ok() -> http.Response { http.text(200, "ok") }
```
