`derive Json` and `derive SqlRow` take one argument, `case:`, which is snake, camel, pascal, or kebab: it converts the keys of the fields without their own wire name. Other derives take no arguments. See core 2.2.

## Example

```xo
struct User {
  user_id: Int
} derive Json(case: shouty)
```

## Fix

```xo
struct User {
  user_id: Int
} derive Json(case: camel)
```
