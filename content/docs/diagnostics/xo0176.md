`pub` exports a declaration from its module (core 1.5). Imports (`use`) and `test` blocks cannot be exported, so `pub use` and `pub test` are rejected. Remove the `pub`.

## Example

```xo
pub test "adds" {
  expect(1 + 1) == 2
}
```

## Fix

```xo
test "adds" {
  expect(1 + 1) == 2
}
```
