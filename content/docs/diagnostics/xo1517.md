`xo build --versioninfo=FILE.json` reads goversioninfo's JSON (FixedFileInfo, StringFileInfo, VarFileInfo, IconPath, ManifestPath; paths relative to the JSON file), `--icon=FILE.ico` an icon file, and `--manifest=FILE` an application manifest, and writes them as the program's resources (decision 0560). A file that is missing, JSON that does not parse, or an icon whose headers are not an ICO stops the build; the message is goversioninfo's.

## Example

```xo
xo build --targets=windows/amd64 --versioninfo=versioninfo.json .   # versioninfo.json missing
```

## Fix

```xo
xo build --targets=windows/amd64 --versioninfo=cmd/app/versioninfo.json .
```
