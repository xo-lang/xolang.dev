An `xml` string is Go's tag text: `name`, `name,attr`, `,chardata`, `a>b>c`, `,omitempty`, or `-`. `attr` takes a Str, Int, Float, or Bool (or an Option of one) and no path; `chardata` takes a Str. `innerxml`, `comment`, and `any` are not supported yet. See core 2.9.

## Example

```xo
struct Item {
  id xml "ID,attr,bogus": Int
} derive Xml
```

## Fix

```xo
struct Item {
  id xml "ID,attr": Int
} derive Xml
```
