Reported by `xo vet` as a warning. `dbg(expr)` prints the expression source and its `Debug` value and returns the value, which is useful while debugging but noise in committed code; `xo build --ci` rejects it. Remove the call and keep the expression, or log through `std/log` if the output is meant to stay. See core 11.4.

## Example

```xo
fn area(w: Int, h: Int) -> Int {
  dbg(w * h)
}
```

## Fix

```xo
fn area(w: Int, h: Int) -> Int {
  w * h
}
```
