Embedded files must come from the module itself, so a build on another machine embeds the same bytes: paths are relative to the declaring file's directory, stay inside it, and name no symbolic link.

## Example

```xo
const KEY: Bytes = embed("../secrets/key.pem")
```

## Fix

```xo
Move the file into the module, next to or below the declaring file.
```

Run `xo explain XO1507` for this text in a terminal, or see
[section 10.6 of the specification](../../spec/core/#106-diagnostic-codes).
