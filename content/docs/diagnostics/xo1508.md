A `Str` holds UTF-8 text. A file with other bytes (an image, a compressed file, text in another encoding) embeds as `Bytes`.

## Example

```xo
const LOGO: Str = embed("logo.png")
```

## Fix

```xo
Declare the constant `Bytes`: `const LOGO: Bytes = embed("logo.png")`.
```
