A field's wire name (`name as "key": T`) is used only by `derive Json` and `derive SqlRow`. On a struct with neither it changes nothing. Add the derive, or remove the wire name. See core 2.2.

## Example

```xo
struct User {
  name as "Name": Str
}
```

## Fix

```xo
struct User {
  name as "Name": Str
} derive Json
```
