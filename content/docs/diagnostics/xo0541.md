A Bytes or Str slice is a view of its parent (decision 0330), not a copy. A receive buffer (`raw.bytes_buf`) read into on every pass of a loop changes under every view kept from an earlier pass: a message list built from `buf[a..b]` ends up showing the last read's bytes. `xo vet` reports such a slice when the loop passes the buffer to a call and the slice, or a local bound to it, is pushed to or stored in a collection or variable declared outside the loop, or returned. Copy what outlives the buffer with `.clone()`; `// xo:allow XO0541 reason` when nothing writes the buffer again.

## Example

```xo
let buf = raw.bytes_buf(4096)
var msgs: List[Bytes] = []
while true {
  let n = recv(fd, buf)
  if n <= 0 { break }
  msgs.push(buf[0..n])
}
```

## Fix

```xo
let buf = raw.bytes_buf(4096)
var msgs: List[Bytes] = []
while true {
  let n = recv(fd, buf)
  if n <= 0 { break }
  msgs.push(buf[0..n].clone())
}
```
