Inside a string, `${` starts an interpolated expression that must be closed by `}` before the string ends. If a literal `${` is meant, escape the dollar sign: `\${`. A `$` not followed by `{` is always literal. See core 1.6.

## Example

```xo
fn f(b: Int) -> Str {
  "a ${b"
}
```

## Fix

```xo
fn f(b: Int) -> Str {
  "a ${b}"
}
```
