Every `fn` declaration outside an interface needs a `{ ... }` body. Only interface method signatures have no body. If the body is not written yet, use a typed hole `???` (core 3.7) so the rest of the program still checks. See core 3.2 and 15.

## Example

```xo
fn f() -> Int
fn g() {}
```

## Fix

```xo
fn f() -> Int { ??? }
fn g() {}
```
