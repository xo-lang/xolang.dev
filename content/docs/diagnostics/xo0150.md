The lexer found a character that begins no Xo token, such as `@` or a stray Unicode symbol outside a string or comment. Xo source is UTF-8 and identifiers are `[A-Za-z_][A-Za-z0-9_]*`. Remove the character or move it into a string literal. See core 1.1 and 1.5.

## Example

```xo
fn f(x: Int) -> Int {
  x @
}
```

## Fix

```xo
fn f(x: Int) -> Int {
  x
}
```
