`use go "path"` generates a binding for the Go package (into `.xo/gobind/` or `$XO_GOBIND_DIR`). This failed: the package was not found by Go's module resolution, does not build, is a `main` package, or the binding generator reported an error (the message carries Go's reason). Check the import path and that the module is available to the Go toolchain; `xo bind <path>` runs the binding step alone. See core 4.4 and decision 0041.

## Example

```xo
use go "example.invalid/nope"

fn f() {}
```

## Fix

```xo
use go "strings"

fn f(s: Str) -> Str { strings.to_upper(s) }
```
