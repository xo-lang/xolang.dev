In the condition of `if`, `while`, `for`, `match`, `requires`, or `ensures`, a `{` opens the body, so a struct literal or struct pattern (`p is Point{x: 0, ..}`) there is ambiguous. Parenthesize the condition, as in Go. The diagnostic carries that fix. See core 1.4.

## Example

```xo
struct Point { x: Int }

fn f(p: Point) -> Bool {
  if p == Point{x: 0} {
    true
  } else {
    false
  }
}
```

## Fix

```xo
struct Point { x: Int }

fn f(p: Point) -> Bool {
  if (p == Point{x: 0}) {
    true
  } else {
    false
  }
}
```
