An embed constant's path is relative to the directory of the file that declares it. A `Str` or `Bytes` constant embeds exactly one file; an `embed.Dir` constant embeds every file a path or glob names (a directory brings its files, except names starting with `.` or `_` unless the pattern starts with `all:`). One embed may hold up to 64 MiB and a program's embeds 256 MiB together.

## Example

```xo
const PAGE: Str = embed("static/*.html")
```

## Fix

```xo
Name one file, or declare the constant `embed.Dir` to embed several.
```
