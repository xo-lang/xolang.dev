The value's type is not the expected one. Xo converts implicitly in exactly three cases, each only where the target type is known: `T` to `T?`, a value to an interface it implements, and an error at `?` to the enclosing error type. Everything else is explicit, including all numeric conversions (`Float(i)`) and newtypes (`Email(s)`). Branches of `if` and `match` must already agree; annotate the binding to give them an expected type. See core 2.10.

## Example

```xo
fn f(i: Int) -> Float { i }
```

## Fix

```xo
fn f(i: Int) -> Float { Float(i) }
```
