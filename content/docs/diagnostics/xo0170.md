In a function type, `uses a, b` would be ambiguous with the comma that separates parameters or fields, so several effects are written `uses (a, b)`. In a declaration clause (`fn f() uses net, clock`) the parentheses are optional. The diagnostic carries a fix that adds them. See core 6.2 and 15.

## Example

```xo
fn f(g: fn() uses net, clock, n: Int) uses (net, clock) {
  g()
}
```

## Fix

```xo
fn f(g: fn() uses (net, clock), n: Int) uses (net, clock) {
  g()
}
```
