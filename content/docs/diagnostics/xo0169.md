`match` and `select` arms are separated by newlines, not commas, so arms read like statements. Remove the comma. See core 3.5.

## Example

```xo
fn f(b: Bool) -> Int {
  match b {
    true => 1,
    false => 2
  }
}
```

## Fix

```xo
fn f(b: Bool) -> Int {
  match b {
    true => 1
    false => 2
  }
}
```
