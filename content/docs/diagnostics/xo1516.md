wasip2/wasm builds wasi:http components, and a host only calls their handle export, so a program that never serves has nothing a host can run. (Decision 0447.)

## Example

```xo
fn main(os: Os) { os.stdio.println("hi") }
```

## Fix

```xo
Call `http.serve_component(r)` from main, or build for wasip1/wasm.
```
