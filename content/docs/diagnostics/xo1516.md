Since 2026-11-02 a wasip2/wasm program that does not serve wasi:http builds as a wasi:cli/command component, whose wasi:cli/run export runs main. (Decision 0447.)

## Example

```xo
fn main(os: Os) { os.stdio.println("hi") }
```

## Fix

```xo
Nothing: build it with --targets=wasip2/wasm and run it with `wasmtime run`.
```
