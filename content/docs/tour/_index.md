Twelve short steps through the language. Every program on these pages is
checked, run, and tested with the current toolchain before the site is
published, and every error message shown is the compiler's real output.

If you know Go, most of Xo will look familiar. The differences are where Go
lets a bug compile: ignored errors, nil, missing cases, data races, leaked
goroutines, and code that reaches the network or the disk without saying so.
