## Install

{{ $r := hugo.Data.release -}}
- Latest release: {{ $r.latest_url }} ({{ $r.version }}{{ with $r.note }}, {{ . }}{{ end }}, released {{ $r.date }}: {{ range $i, $p := $r.platforms }}{{ if $i }}; {{ end }}{{ $p.label }}{{ end }}; plus SHA256SUMS; the macOS binaries are notarized and the Windows ones Authenticode signed). Download `xo-{{ $r.tag }}-<os>-<arch>.tar.gz`, check it against SHA256SUMS, unpack it, and put its `bin` directory on PATH; `bin/xo` finds the standard library at `../lib/xo`, so keep the directory together. `xo version` prints the version and platform.
- License: {{ $r.license }} ({{ $r.license_url }}).
- Steps per platform: [Getting started, Install]({{ with site.GetPage "/docs/getting-started" }}{{ (.OutputFormats.Get "markdown").Permalink }}{{ end }}). Building from source is the alternative on the same page.
