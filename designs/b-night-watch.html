The compiler is the code reviewer your agents answer to.

Xo is a small, statically typed language for backends. Every check speaks JSON with stable codes and ready-made fixes, so an agent can write, check, and repair a service without a human in the loop.

$ get started diagnostic codes
xo check --json ./main
