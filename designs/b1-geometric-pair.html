Agents write the code. The compiler reviews every line.

Xo is a small, statically typed language for backends and web services. Every check reports JSON with stable codes and ready-made fixes, so an agent can write, check, and repair a service before it ever reaches review.

$ get started diagnostic codes
xo check --json ./main

Ideas from great languages, in one small one.

Xo borrows what has proven itself in Go, Rust, Swift, and Kotlin, then keeps the language small enough to hold in your head. The bugs tests usually miss become compile errors: in a study of 30 planted safety bugs, Xo caught or prevented 23 to 29, against 13 for Go with strict analyzers and 9 for plain Go.

from Go

Small and fast

Few keywords, one obvious way, one formatter, fast builds, and static binaries for linux, darwin, windows, and wasi.

from Rust

Errors you can't ignore

Result and ?; an unhandled error is a compile error.

from Rust and ML

Sum types, exhaustive match

Every case handled, and every match target.os arm type checked for every target.

from Swift and Kotlin

No nil

Optionals are T? and checked at every use.

from Swift and Kotlin

Structured concurrency

No task outlives its scope; value semantics mean no data races.

Effects you can see

interop · Go

Use any Go package

Bindings are generated on the fly. (T, error) becomes T ! go.Error, and a nil pointer becomes T?.

use go "regexp"
use go "github.com/google/uuid" as uuid
interop · C

Call C from native builds

The LLVM and arm64 backends bind C headers directly, with effects declared at the boundary.

use c "zlib.h" link "z" uses none
// zlib.crc32(0, b"hello")
// one binary
