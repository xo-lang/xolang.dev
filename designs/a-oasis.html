EXPERIMENTAL · v0.9

Backends that agents can't quietly break.

Xo is a small, statically typed language for web services. It keeps what makes Go productive and moves the bugs tests usually miss into the compiler.

Get started Read the spec
users.xo
use std/http

pub enum ApiErr {
  BadRequest(msg: Str)
  NotFound(id: Int)
}

fn (s: Store) get(id: Int) -> User ! ApiErr
  requires id > 0 else ApiErr.BadRequest(msg: "id must be positive")
{
  s.users.with(fn(m) { m.get(id) }).or_err(ApiErr.NotFound(id: id))?
}

fn main(os: Os) ! {
  let store = Store{users: Mutex.new({1: User{id: 1, name: "Ada", email: None}})}
  var r = http.router()
  r.handle("GET /users/{id:Int}", fn(req) -> http.Response ! ApiErr {
    http.json(200, store.get(req.param_int("id"))?)
  })
  http.server(os.net.listen(":8080")?, r).serve()?
}

Let Finan sleep through the night

Diagnostics come back as JSON with stable XO codes and machine fixes, so an agent repairs its own code before it reaches review, and the pager stays quiet.

Fennec foxes sleep through the desert heat and hunt at night. Your services should only need one of those.
