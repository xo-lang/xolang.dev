# xolang.dev

The website of the [Xo language](https://github.com/xo-lang/xo), built with
[Hugo](https://gohugo.io) and published to GitHub Pages by
`.github/workflows/pages.yml` on every push to `main`.

## Commands

```sh
# Hugo v0.167.0, built from source (Homebrew has no macOS 27 bottle).
CGO_ENABLED=0 GOBIN=$PWD/.tools/bin go install github.com/gohugoio/hugo@v0.167.0

.tools/bin/hugo server          # http://localhost:1313, live reload
.tools/bin/hugo --gc --minify   # build into public/

# A page whose front matter `date` is later than the build time is left
# out with no warning (Hugo's buildFuture is off). Date release pages and
# posts at or before the moment you publish, with an offset
# (2026-10-27T15:50:00-04:00), and check the page is in public/ after a
# build. This has dropped pages several times (latest: the 0.33 notes).

# Refresh the spec, release notes, and diagnostic code pages from the Xo
# repo (default ../../codelang, or $XO_REPO, or a path argument). Builds
# cmd/xo from that repo for `xo explain`, unless $XO names a binary.
python3 scripts/sync-content.py

# Check, run, and test every tour example and record the outputs the pages
# show (needs xo: XO=path/to/xo or xo on PATH). Run after editing an example
# or after an Xo release, then commit.
XO=path/to/xo scripts/check-examples.sh
```

## Layout

| Path | Contents |
|---|---|
| `hugo.toml` | Site config: menu, the orange announcement bar (`params.announcement`), output formats |
| `layouts/home.html` | The home page (its status summary reads `data/roadmap.toml`) |
| `data/roadmap.toml`, `layouts/roadmap.html`, `layouts/roadmap.markdown.md`, `layouts/_partials/stages.html` | The roadmap: every milestone and plan stage (status done, now, or next) in one file, shown in full on `/roadmap/` and summarized on the home page; edit the data, not the templates |
| `layouts/baseof.html`, `layouts/_partials/` | Shared page shell: announcement bar, header, footer |
| `layouts/docs/`, `layouts/blog/` | Docs (sidebar and table of contents) and blog layouts |
| `layouts/home.llms.txt`, `layouts/home.llmsfull.txt`, `layouts/page.markdown.md` | `/llms.txt` (an index), `/llms-full.txt` (the FAQ, Getting started, Xo and Go, the tour and the latest release notes, whole), and the raw Markdown of every page (`<page>/index.md`) for agents |
| `data/release.toml`, `layouts/_shortcodes/release.html`, `release-archives.html` | The current release's facts (version, tag, date, archives, license) in one place; pages read them with `{{</* release "version" */>}}` and the archive table with `{{%/* release-archives */%}}`. Update the file with each release; `scripts/check-facts.sh` (also run by the Pages workflow) fails when a page names a release version itself or the file's tag is not the newest release page's |
| `layouts/_partials/seo.html` | Canonical URL, Open Graph and Twitter tags, and schema.org JSON-LD: `SoftwareApplication`, `WebSite` and `Organization` on the home page, `FAQPage` on the FAQ (from its `##` questions and each answer's first paragraph: start every answer with a direct sentence), `TechArticle` on pages, `BreadcrumbList` below the top level |
| `layouts/robots.txt` | Every crawler allowed, answer engines and AI assistants named, and the sitemap; `hugo.toml`'s `enableGitInfo` dates each page in `sitemap.xml` by its last commit (the workflow checks out the full history) |
| `assets/css/main.css` | All styles (dark first, light via `prefers-color-scheme`) |
| `content/docs/spec/`, `content/docs/diagnostics/`, `content/blog/v*.md` | Generated by `scripts/sync-content.py` (spec, `xo explain --json`, CHANGELOG.md); edit the Xo repo, not these |
| `content/docs/*.md`, `content/docs/tour/` | Hand written docs and the tour |
| `examples/tour/<name>/` | The tour's programs (`{{%/* example "name" */%}}` shows `main.xo` and `output.txt`) |
| `examples/mistakes/<name>/` | Programs with one mistake each (`{{%/* mistake "name" */%}}` shows `main.xo` and the real `check.txt`) |
| `static/` | Images (Finan the fennec fox), icons, `CNAME`, and the self-hosted fonts (`static/fonts/`, Space Grotesk and JetBrains Mono, SIL OFL; no requests to Google's font hosts) |
| `designs/` | The design mockups the site came from (not published) |
| `designs/assets/finan-avatar-dark.png`, `finan-avatar-orange.png` | Finan as a square avatar (752x752, the GitHub organization picture; dark is the one in use), made from `static/images/finan-soft-alert.webp` at its native size |

The announcement bar text lives in `hugo.toml`; set `enabled = false` to hide it.

## Playground

`/play/` checks, compiles, and runs Xo entirely in the visitor's browser
(decisions 0144 and 0242 in the xo repo); there is no server.

- `scripts/build-playground.py [xo repo]` builds the page's WebAssembly into
  `static/play/assets/` and `static/play/manifest.json`: `xoc` (the Xo
  compiler with its own wasm backend, selfhost/wasm built for wasm by
  itself, run with `--play check|fmt|build`) and `std` (a bundle of std's
  sources), brotli compressed and named by hash, about 2 MB in all. Rerun
  it after compiler or std changes; it needs the repo's `bin/xo`.
- `assets/js/play/`: `play.js` (page), `highlight.js` (editor coloring),
  `toolchain.js` (worker running the compiler over an in-memory file
  system), `runner.js` (one worker per run).
- No `use go` (refused with a clear message), no generated Go tab, and no
  tests yet; the Go-era playground that had them (Go's compiler and linker
  in the tab, 23.5 MB) is in git history and decision 0242.
- Tour examples link to `/play/#example=tour/<name>` (shortcodes `example`
  and `mistake`).
- Test: `.tools/bin/hugo --gc --minify && node scripts/test-playground.mjs`
  (headless Chrome; every example, the mistakes' codes, the safety limits,
  the download notice, links, highlighting, the phone layout, and the run
  times). Run it after rebuilding the playground.
- Safety: a Content Security Policy on the page (scripts from this site
  only, `connect-src 'self'`); programs may import only WASI, see no files,
  network, or environment, and are capped at 1 GiB, 1 MB of output, and
  10 s; shared links keep the code in the URL fragment, which is never sent
  to a server, and run only when the visitor presses run.
- Vendored unchanged: `static/play/vendor/browser_wasi_shim-0.4.2/`
  (`@bjorn3/browser_wasi_shim`, MIT/Apache-2.0) and
  `static/play/vendor/brotli-decode-1.1.0/` (`js/decode.js` of google/brotli,
  MIT). Assets are brotli compressed (the `brotli` command is needed to
  build them).
- CI: `.github/workflows/pages.yml` runs the playground test before every
  deploy.
